# outoforbitdev

I build things I want to exist. Sometimes they're tools to make my life easier, sometimes they're niche websites or applications. Most of them are weird and intentionally not for everyone, and that's the point.

## Guiding Principles

### Minimize Harm
I think carefully about what I build. This means not creating software that will hurt someone, but also considering the costs of what I make. Environmental impact, external dependencies, stability. I'm cautious about sharing libraries that could put others at risk, and I try to reduce the blast radius of my work.

### Maximize Joy
When we've minimized harm, we should do what we can to make people happy and make their lives easier. Not everything needs to be optimized for scale or traffic.

### Be Weird
The internet has gotten too homogenous. The web of the 2000s was messy and sometimes chaotic, but it was also diverse and interesting ideas flourished. Today, everything is optimized for algorithms and engagement, and most websites look the same. I want to build things that small groups of people genuinely love, rather than things everyone will tolerate.

## Featured Projects

### [muster](https://github.com/outoforbitdev/muster)
A CLI tool for managing multi-repo workspaces. If you work across multiple repositories and want a unified way to manage dependencies, run scripts, and coordinate changes, muster makes it easier. It's built for developers who value simplicity and clarity over bloated abstractions.

### [app-galaxy-map](https://github.com/outoforbitdev/app-galaxy-map)
A full-stack application for exploring and visualizing a galaxy map. Built with a .NET backend and React frontend, it demonstrates how to create an interactive, visually interesting web experience. It's the kind of project that exists because it's fun and cool, and that's enough reason.
